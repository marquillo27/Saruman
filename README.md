# Project Saruman

A pixel-art fantasy platformer inspired by *The Lord of the Rings* and *Game of Thrones*, built in Python with [pygame-ce](https://pyga.me/). Sprites, terrain, levels and audio are generated by the scripts in `tools/`; the painted parallax backdrops were generated locally with Stable Diffusion (see [Credits](assets/CREDITS.md)).

> **Status:** version 2.0 (October 2026) — reworked movement, new art, 4–5× longer levels with checkpoints and hidden relics. Three worlds, three bosses, win screen and credits.

## The game

Fight your way through **three biome-distinct worlds** — 12 main levels plus one secret — each ending in a boss fight:

| World | Biome | Levels | Boss |
|---|---|---|---|
| I — Greenwood | Forest | 3 (+1 secret) | Boss Warg |
| II — Scorchlands | Fire & ash | 4 | Goblin King |
| III — Frozen North | Ice | 5 | Night King |

### Features

- Responsive movement with inertia: acceleration and braking, shaped jump arc (tap for a hop, hold for a full jump), double jump, coyote time, wall slide and wall jump
- Long levels (300–600 tiles) built from hand-designed segments, with checkpoints — falling into a pit costs one life and returns you to the last lit brazier
- Two hidden relics per level behind fake walls; bosses seal the exit until they fall
- Combat: staff strike, two-level projectiles, shield/parry, enemy stomp
- 12 enemy types, from Goblinkin and Wraiths to two-phase bosses
- Stackable lives (up to 7 hearts) and random timed bonuses: shield, nuke, fruit frenzy
- 480×270 pixel view with painted backdrops, per-world terrain, weather and color grading; 7 music tracks + SFX
- Save system, settings, highscores
- ~600 unit tests

### Controls

| Action | Keys |
|---|---|
| Move | ← / → or A / D |
| Jump (hold for higher) | Space, ↑, W or Z |
| Wall jump | Jump while sliding down a wall |
| Shoot | J or X |
| Melee swing | K or C |
| Shield / parry | L or Q |
| Pause menu | Esc |

## Getting the game

**Just want to play? (Windows)** Download `ProjectSaruman-windows-portable.zip` from the [latest release](https://github.com/marquillo27/Saruman/releases/latest), unpack it anywhere and run `ProjectSaruman.exe`. Fully portable — no installation, no Python needed. (Windows SmartScreen may warn about an unknown publisher: choose *More info → Run anyway*.)

**Want the source code?**

- **Without git:** click the green **Code** button at the top of this page → **Download ZIP**.
- **With git:**

  ```
  git clone https://github.com/marquillo27/Saruman.git
  ```

## Running from source

Requires Python 3.12+ and [uv](https://docs.astral.sh/uv/):

```
uv sync
uv run python -m saruman
```

The first command installs all dependencies into a local `.venv`; the second starts the game. No system-wide installation, nothing outside the project folder is touched.

## Tests

```
uv run pytest
```

## Building a Windows executable

```
.\build.ps1
```

Produces a standalone build in `dist/ProjectSaruman` via PyInstaller (see `ProjectSaruman.spec`).

## What's in the code

```
saruman/          game code
├── core/         engine backbone: game loop, state machine, input mapping,
│                 asset loading, audio
├── states/       screens the game moves between: menu, play, pause,
│                 world intro cards, game over, credits, settings, highscores
├── entities/     player, 11 enemy types (incl. three bosses), items,
│                 projectiles, interactive objects, triggers
├── world/        level loading (.tmx), tilemap and per-world terrain skins,
│                 camera, parallax layers, weather, particles
├── physics/      collision detection and resolution
├── ui/           HUD (hearts, score) and visual theme
└── save/         settings and highscores persisted to disk

assets/           sprites, backdrops, tilemaps (.tmx), audio, fonts
tools/            the generators behind the assets: hero and enemy sprites
                  (generate_hero.py, generate_enemies.py), level maps
                  (level_forge.py, checked by reach_check.py), backdrops
                  (process_backgrounds.py), sound effects and music
tests/            pytest suite (~600 tests) covering gameplay logic
```

A good place to start reading is `saruman/main.py` (entry point) and `saruman/states/play.py` — the heart of the game where levels, the player and enemies come together. Level progression is a simple dict chain (`_NEXT_LEVEL`) in the same file.
